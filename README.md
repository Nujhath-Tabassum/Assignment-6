1.Project Name:FitLog


2.Description:-
FitLog is a workout library and daily workout planner that helps users explore exercises, create a daily workout plan, and save workouts for later. Users can view workout details, track their planned exercises, and manage their saved workouts through a simple and responsive interface.


 3.Technologies Used;-

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify
- REST API
- Local Storage


4.Key Features:-

Workout Library
- Browse workouts covering different muscle groups with information such as equipment, duration, calories, and rating.

2.Workout Details
- View detailed information about each workout, including instructions, specifications, and workout statistics.

3.Daily Workout Plan
- Add workouts to today's plan with a maximum of five exercises.

Save Workouts
- Save workouts for later and access them from the Saved section.

Plan Management
- Mark workouts as completed, remove workouts from the plan, and view total exercises, minutes, and calories.
